Comment obtenir un mot de passe d'application Gmail ?
1
Activez d'abord la Validation en 2 étapes sur votre compte Google :
myaccount.google.com → Sécurité → Validation en 2 étapes
2
Accédez directement aux mots de passe d'application :
myaccount.google.com/apppasswords (n'apparaît que si la 2FA est activée)
3
Dans le champ "Nom de l'application", tapez ContactPro → cliquez Créer
4
Copiez le code à 16 caractères généré (ex: abcd efgh ijkl mnop) et collez-le dans le champ ci-dessus
Important : utilisez un mot de passe d'application, pas votre mot de passe Gmail habituel. Google bloque les connexions directes depuis 2022.
